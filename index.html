    Canva

    Bring in an email from Canva

    1. In Canva, design your email using the Email design type.
    2. Choose Share, then the HTML export option, then Copy HTML.
    3. Paste it into the box below, or open the downloaded .html file.
    4. Check the preview, then press Copy for Outlook and paste into a new email.
    If pictures are missing from the preview, they were saved as separate files rather than web links. Use Canva's Copy HTML option instead of the download.
    Canva keeps text as real text only when you use text boxes. Anything grouped or placed over a picture is flattened into a single image, which colleagues cannot read if images are blocked.
